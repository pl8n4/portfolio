## Directory Purposes

**src/**
- Purpose: All React application source code
- Contains: TypeScript/TSX files, styles, assets
- Key files: `main.tsx` (bootstrap), `App.tsx` (main component)
- Subdirectories: `styles/`, `assets/`, `components/` (empty)

**src/styles/**
- Purpose: CSS styling with design system
- Contains: `global.css` (731 lines)
- Key sections: Design tokens, base styles, components, responsive, animations

**src/assets/**
- Purpose: Static images and documents
- Contains: JPG images (photos), PNG images (diagrams), PDF (poster)
- Files:
  - `headshot.jpg` - About section profile image
  - `arg.jpg`, `soccer.jpg`, `ski.jpg` - Gallery photos
  - `EPL_ERD.png`, `FilmfiendSystemArch.png`, `FocusPredict_system_diagram.png` - Project diagrams
  - `mri_poster.pdf` - Research poster

**public/**
- Purpose: Static assets served as-is
- Contains: Favicon files (ico, png, apple-touch-icon)

**dist/**
- Purpose: Production build output
- Contains: Bundled JS, CSS, assets (generated by `npm run build`)
- Note: Gitignored

**.github/workflows/**
- Purpose: GitHub Actions CI/CD configuration
- Contains: `azure-static-web-apps-black-mud-0791fa010.yml`

## Key File Locations

**Entry Points:**
- `index.html` - HTML template with root div and font preloads
- `src/main.tsx` - React bootstrap (mounts App to DOM)

**Configuration:**
- `tsconfig.json` - TypeScript root (project references)
- `tsconfig.app.json` - App config (ES2022, JSX, strict mode)
- `tsconfig.node.json` - Build tool config (ES2023)
- `vite.config.ts` - Vite build configuration
- `eslint.config.js` - Flat ESLint config

**Core Logic:**
- `src/App.tsx` - All UI logic, state management, content (414 lines)

**Styling:**
- `src/styles/global.css` - Design system and all component styles

**Documentation:**
- `README.md` - Getting started, scripts, deployment info

## Naming Conventions

**Files:**
- PascalCase for React components: `App.tsx`
- camelCase for entry files: `main.tsx`
- kebab-case for config: `eslint.config.js`, `vite.config.ts`
- kebab-case for styles: `global.css`
- lowercase for assets: `headshot.jpg`, `soccer.jpg`

**Directories:**
- lowercase: `src/`, `public/`, `dist/`
- Plural for collections: `styles/`, `assets/`, `components/`

**Special Patterns:**
- `.tsx` for React components with JSX
- `.ts` for TypeScript without JSX
- `tsconfig.*.json` for TypeScript project references

## Where to Add New Code

**New Component:**
- Implementation: `src/components/ComponentName.tsx`
- Styles: Add to `src/styles/global.css` or create component CSS
- Note: Currently no component extraction exists

**New Style Section:**
- Location: `src/styles/global.css`
- Pattern: Add section with `/* ===== SECTION NAME ===== */` header

**New Asset:**
- Images: `src/assets/image-name.jpg` or `.png`
- Documents: `src/assets/document.pdf`
- Import in component: `import name from './assets/filename.ext'`

**New Configuration:**
- Root level for build tools
- Follow existing naming patterns
